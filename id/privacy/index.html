Kebijakan privasi

Terakhir diperbarui: 27 Oktober 2026

Singkatnya: Boxwright tidak mengumpulkan data apa pun. Semua yang kamu isi tetap di HP kamu.

Data yang saya kumpulkan

Tidak ada. Boxwright tidak punya akun, analitik, iklan, laporan crash, atau pelacakan dalam bentuk apa pun. Di dalamnya tidak ada kode pihak ketiga yang mengumpulkan data.

Yang tetap di HP kamu

Box kamu, speaker buatan sendiri, koreksi pada daftar speaker dan pengaturan disimpan di penyimpanan pribadi aplikasi di HP kamu. Saya tidak bisa melihatnya dan tidak punya salinannya.

Izin

Boxwright tidak meminta izin apa pun. Cek nada memutar suara lewat output audio HP kamu; mikrofon tidak dipakai. Tidak ada akses ke kamera, lokasi, kontak, notifikasi atau Bluetooth.

Cadangan, ukuran potong dan kartu box

Cadangan berupa satu file, kartu box berupa gambar, file proyek dibuka di Boxwright pada HP lain, dan lembar kerja PDF berupa dokumen. Menu bagikan atau pemilih file di HP kamu mengirimnya ke tempat yang kamu pilih. Layanan tersebut mengurus file itu sesuai kebijakan privasi mereka sendiri. Saya tidak pernah menerimanya.

Cadangan HP

Kalau cadangan bawaan HP kamu aktif (Google atau iCloud), data Boxwright bisa ikut tercadangkan, sama seperti data kebanyakan aplikasi. Google dan Apple mengurus cadangan itu sesuai kebijakan privasi mereka sendiri.

Jaringan

Boxwright tidak membuat koneksi jaringan sendiri. Satu-satunya pengecualian adalah pembelian: membeli atau memulihkan Pro diurus oleh Google Play atau Apple App Store sesuai kebijakan privasi mereka. Saya tidak menerima data pembayaran kamu. Aplikasi hanya menerima status pembelian dari toko dan menyimpannya di HP kamu.

Email

Kalau kamu mengirim email ke saya, saya menerima alamat email dan pesan kamu. Keduanya hanya saya pakai untuk membalas, tidak saya bagikan ke siapa pun, dan kamu tidak saya masukkan ke milis apa pun. Minta kapan saja, nanti saya hapus.

Situs ini

Situs ini tidak memakai cookie, tidak memakai analitik dan tidak memuat apa pun dari server lain. Kalkulatornya jalan di browser kamu; yang kamu ketik tidak dikirim atau disimpan, dan hilang saat halaman ditutup. Situs ini di-host di GitHub Pages; GitHub bisa mencatat data teknis seperti alamat IP untuk keamanan, seperti dijelaskan di pernyataan privasi GitHub sendiri.

Anak-anak

Boxwright adalah alat untuk membuat box speaker. Aplikasi ini tidak ditujukan untuk anak-anak dan tidak mengumpulkan data dari siapa pun.

Hak kamu

Saya tidak menyimpan data aplikasi tentang kamu, jadi di pihak saya tidak ada yang perlu dibuka, dikoreksi atau dihapus. Untuk menghapus semua yang ada di aplikasi, hapus aplikasinya. Untuk email yang pernah kamu kirim, kabari saya dan akan saya hapus. Kamu juga bisa mengadu ke lembaga pelindungan data pribadi di negara kamu.
